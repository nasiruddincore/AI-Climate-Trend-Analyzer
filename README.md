An industry-oriented data science project designed to analyze decades of historical climate data. This system detects long-term global warming trends, identifies extreme weather anomalies using statistical thresholds, and utilizes Machine Learning to forecast future temperatures based on carbon emissions.

---

## 📌 Problem Statement
Climate change requires data-driven policy making. However, raw environmental data is noisy and highly volatile. This project solves this by filtering daily weather noise to uncover true warming trends, flagging extreme anomalies, and providing a predictive engine to forecast future climate states.

## 🎯 Industry Relevance
Similar predictive analytics systems are utilized by:
* **Smart City Planners:** To prepare infrastructure for predicted heatwaves.
* **Agritech Companies:** To forecast rainfall and optimize crop cycles.
* **Environmental Agencies:** To track the correlation between CO₂ emissions and global temperatures.

## 🏗️ Architecture & Tech Stack
* **Virtual Data Generation:** Python, Numpy (Mathematical seasonality simulation)
* **Data Processing & ML:** Pandas, Scikit-Learn (Random Forest Regressor)
* **Interactive UI:** Streamlit, Plotly (Interactive Web Dashboard)
